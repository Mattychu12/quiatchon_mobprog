Laboratory Discussion
In this activity, I learned how to organize a Flutter project using proper file structuring and design patterns. I also learned the importance of separating widgets and application components to make the code more organized, reusable, and easier to maintain. I used the Provider package for state management and explored how Flutter widgets can be used to display images, user profile avatars, and interactive buttons. For the enhancements, I implemented image widgets for displaying photos, customized the user profile avatar, and used widget-based like and comment buttons to improve the application's interface. This activity helped me understand the importance of code organization, reusable widgets, and state management in Flutter development. Through this activity, I improved my knowledge of Flutter project structure and learned how to create a more organized and maintainable mobile application.
